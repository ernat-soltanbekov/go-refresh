# Go-Refresh

## Описание
Проект `go-refresh` — это консольная утилита для глубокой обработки и трансформации текста. Включает в себя конвейер (pipeline) различных фильтров и модификаторов:
- Определение языка (Английский / Французский) с помощью флага `--lang`
- Извлечение ключевых слов с помощью флага `--keywords`
- Исправление пробелов, пунктуации и групп знаков (`...`, `!?`)
- Форматирование одинарных кавычек `'`
- Грамотное использование артиклей (`a` / `an`)
- Конвертация чисел и изменение регистра текста (`hex`, `bin`, `up`, `low`, `cap`)

## Правила трансформации
В тексте обрабатываются следующие теги и правила:
- **Конвертация чисел:** 
  - `(hex)` — заменяет предшествующее слово на его десятичный эквивалент из шестнадцатеричной системы.
  - `(bin)` — заменяет предшествующее слово на его десятичный эквивалент из двоичной системы.
- **Управление регистром:**
  - `(up)` / `(low)` / `(cap)` — переводят предыдущее слово в верхний регистр, нижний регистр или делают первую букву заглавной.
  - Модификаторы количества (`(up, N)`, `(low, N)`, `(cap, N)`) — применяют форматирование к указанному количеству ($N$) предыдущих слов.
- **Пунктуация и пробелы:** 
  - Знаки препинания (`.`, `,`, `!`, `?`, `:`, `;`) прижимаются к предыдущему слову и отделяются пробелом от следующего. Сложные группы (например, `...` или `!?`) остаются сгруппированными.
- **Кавычки:**
  - Одинарные кавычки (`'`) выравниваются по границам слов без лишних внутренних пробелов.
- **Артикли:**
  - Автоматическая замена артикля `a` / `A` на `an` / `An`, если следующее слово начинается с гласной буквы или `h`.

## Доступные флаги
- `--lang` — определяет, написан ли текст преимущественно на английском или французском языке, и выводит результат в stdout.
- `--keywords` — извлекает и выводит топ-5 ключевых слов из обработанного текста (обновление 27-29 июля 2026).

## Запуск проекта
Для запуска программы с входным и выходным файлами используйте команду:
```bash
go run cmd/go-refresh/main.go sample.txt result.txt
```
